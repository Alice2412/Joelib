# I. Contributing Guidelines

We the people of the Joe team welcome any additional studies and documents about the Joe universe. If we don't know you, please create a pull request in a separate branch, we will review your contribution. We will definitely accept any additional documents if it is Joe-related.

# II. Branches

To create or fix something inside the repository, you need to create branches and PRs so we can review. 

- When **creating a coding project**, name the branch by your project name. For example, the project "Joe Physics Lab Development" can be named as `joe-physics-lab-dev` or `joe-physics-lab`. However we still recommend the naming of `-dev`, because we then know that you are still developing. If you are uploading a finished project that is ready to review, and does not need any changes before our review, you may name it as `-release`.
- When **fixing a coding project**, name the branch by the project name `-fix`, and a slash followed by the fixing number. For example, if this "Joe Physics Lab Development" is already merged and you want to fix it, create a branch called `joe-physics-lab-fix/1` which is the first fix. After this is done and merged, you can then create `joe-physics-lab-fix/2`. Naming by date is also available like `joe-physics-lab-fix/11-08`.
- When doing a **literature project**, share the document visible to everyone with the link. When complete, create a branch using the project name -lit. For example, when creating the "Joeclaration of Joedependence", you can name the branch as `joeclaration-of-joedependence-lit`, so we know that it is not a coding project. The best form to upload is PDF or TXT.
